# PetFace

Proyecto universitario: web de adopción de mascotas. El contexto completo del proyecto (análisis, arquitectura, decisiones, roadmap, diseño) vive en el vault de Obsidian `vault/`. Empieza por `vault/00 - Inicio.md`.

- Al tomar una decisión de arquitectura, agrégala como ADR en `vault/04 Decisiones/`.
- Al terminar una sesión, añade una entrada en `vault/06 Bitacora/` y marca el avance en `vault/03 Roadmap/Roadmap.md`.
- Comandos: `npm run dev` (todo), `npm run db:up`, `npm run db:reset`. Ver README.
- Mantener la arquitectura simple: es un proyecto universitario.
